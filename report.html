Introduction

I chose my website to be focusing on lifestyle contents as I like things to be not so serious, and personally, I enjoy reading lifestyle related articles as I get to learn and bookmark some informations for my next use.

I implemented the Webbed website structure (AKA network model) for my website. This structure allows interlinking between the pages so everything is connected and can be accessed with minimal clicks. This will be very convenient to users if they would like to navigate to other article categories after they have finished reading an article.


Inspiration

I was first inspired by EatBook.sg and DanielFoodDiary. These 2 are Singapore's local food blog, where they share lots of reviews and recommendations of different food places. As a foodie myself, I had to include food as part of my content, but realise it was not enough for the assignment requirement, so I branched out to several news network, such as The Straits Times, TODAY, Channel NewsAsia (CNA). Eventually, my main categories of my articles are inspired from CNA Lifestyle!


Accessibility

  1. Firstly, I tried my best to use the best contrasts for all the color schemes on my website. The colors of my text are either a dark shade of green, black, blue, red and pink, and they are all displayed against white-ish background. So there is high color contrast, which is helpful for users with visual impairement.

  2. Secondly, the videos inside the articles are fairly accessible. The embed videos do not auto-play, and for those that do, the sound is not on. Most of the videos have caption, which can be activated. All images have Alt Text as well, which allows visual impaired users who uses a screen reader, to understand what the picture is.

  3. Lastly, all the contents are accessible by keyboard by pressing "tab" and or "arrow" keys. I have tried and tested myself, by using the "tab" key, it will run through each content in order, from top to bottom of the page. The "arrow" key will aid keyboard users in running through the content with ease.


Usability

  1. Firstly, while I make sure that my website is optimized for the desktop version, I also made sure that it is optimized for any other screen types, such as phone, tablet, etc. The layout will adjust accordingly based on what users use to view the website. Users will be frustrated to see a broken website with contents beinng cut off here and there.

  2. Secondly, I aimed for my website to be clean. Since it's a news magazine, it's nothing too fancy, and straight to the point. Users will be able to see the different categories of articles available, and navigate to the respective articles. Of course, I had to reference to other newsletter websites to get a feel of what users will expect from a news magazine website, and they had a clean and professional look.

  3. Lastly, I aimed for my website to have high performance. No one, even myself, wants a website that takes forever to load, and is laggy while trying to navigate around. As my website contains lots of high quality photos, it takes up alot of space as well, which will lead to a slow website. To tackle that, I compressed each photo to its best, so that I can provide the sharpest photo with the smallest size. This allows my website to load faster!


Learning

  1. There were many things to learn, but the first thing was the usage of div, and changing the style of the div to fit the content in layouts that I want. For my articles page, there are two main divs in a page, where one contains the main content, and another contains the mini trending article cards. I had to research on how to display the div side by side, by using float, flexbox, grid, etc. There were alot of trial and errors to see which fits well, and how to make use of the margins and paddings to make it look better.

  2. The second thing I had to learn was the creation of a responsive and sticky navigation bar. Making it responsive was difficult, as I trying ways to make it into a hamburger when the screen becomes smaller, but it wouldn't work. So I decided to make it in a way that the navbar menu will be minimized into a column form. Though it is not as good looking, and takes up lots of space, it is something that I know how to do!
    As for the sticky part, I had to learn from W3Schools, as I wasn't familiar on how to do it on my own. Thanks to W3Schools, I could understand the JavaScript needed for the sticky navigation bar to happen, and will be able to implement it by myself in the future!

  3. The third thing was the cards displaying the articles. I was looking for a way to display details of articles, without just the whole page filled with texts and lines, and no pictures. I believe users will like something short and sweet, and something that will capture more of their attention, which would be pictures! So I went onto CodePen to look for great designs of cards, and referenced the codes used, and tweak it to my own. Now, the article card showcases images, short title and descriptions, as well as categories they fall under!

Evaluation I

I think the user interface of the website is fairly successful, as it is easy to navigate. My website is not cluttered, with all the categories and articles laid out clearly, and users will know where to go.

I also think that the color scheme of the website is great. The main colors for the text and background contrast well with each other. Any other text colors also complement well, making it easy for any user to read.

Evaluation II

I think the layout and design of each articles, as well as the index pages for each article category can be improved by being more diverse. All the articles now follow a standard layout template, with slight changes in text designs here and there. As for the index pages for each article category, it follows the exact same template as the main index page.

Given another time, I would add more description to the category index pages, so as to make it look more lively and informative. I would also make the design of the main index page more captivating. Afterall, the contents I am showing is lifestyle related, so it should not look as formal looking as a proper news website. Given the timeframe and skillset that I have, it is challenging, but I believe I will be able to accomplish it in the future.
